Section 1: QuantumFlow Language Grammar Definition (CFG)

Custom Keywords & Operators

module : Function declaration
initiate ... end : Block scope
when / otherwise : If / Else
cycle : While Loop
show / yield : Print / Return
:= : Assignment
.+., .-. : Add, Subtract
==?, !=?, >>>, <<< : Relational

Formal Context-Free Grammar (EBNF Production Rules) 

Program       ::= ( Statement )*
Statement     ::= ModuleDef | VarAssign | WhenStmt | CycleStmt | YieldStmt | ShowStmt
ModuleDef     ::= "module" IDENTIFIER "(" [ ParamList ] ")" ":" Block
Block         ::= "initiate" Statement* [ "end" ]
VarAssign     ::= IDENTIFIER ":=" Expr
WhenStmt      ::= "when" Expr Block [ "otherwise" Block ]
CycleStmt     ::= "cycle" Expr Block
YieldStmt     ::= "yield" Expr
ShowStmt      ::= "show" "(" Expr ")"
Expr          ::= LogicalOr
LogicalOr     ::= LogicalAnd ( "|||" LogicalAnd )*
LogicalAnd    ::= Relational ( "&&&" Relational )*
Relational    ::= Additive [ ( "==?" | "!=?" | ">>>" | "<<<" ) Additive ]
Additive      ::= Multiplicative ( ( ".+." | ".-." ) Multiplicative )*
Multiplicative::= Primary ( ( ".*." | "./." ) Primary )*
Primary       ::= NUMBER | STRING | IDENTIFIER | "(" Expr ")"
